# Bwbensonjr Emit

## How do I install these formulae?

`brew install bwbensonjr/emit/<formula>`

Or `brew tap bwbensonjr/emit` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bwbensonjr/emit"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
